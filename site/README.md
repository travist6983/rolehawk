# RoleHawk site

The one-page marketing site, served by GitHub Pages at <https://travist6983.github.io/rolehawk/>.
Plain HTML, CSS, and a little JavaScript: no build step, no framework, no third-party requests.

- `index.html`, `styles.css`, `theme.js`, `site.js`: the page. It reuses the app's design
  rather than a look of its own: the tokens from `frontend/src/index.css` under the same
  names, the espresso sidebar, the page header, the italic phase headings, the card lift, the
  small caps labels, and the pill buttons. Change the tokens here when the app's change.
- `fonts/`: Newsreader, Public Sans, and IBM Plex Mono (Latin subsets, SIL Open Font License).
- `stills/`, `social.png`, `icon-180.png`: generated by `tools/make_assets.py` from
  `docs/media`. Run it again when a GIF there changes.
- Screenshots and GIFs are not copied here: `tools/build.py` copies `docs/media` into the
  built site as `media/`, so the README and the site share one set.

Preview locally:

```bash
python3 site/tools/build.py _site
python3 -m http.server --directory _site 8080
```

`build.py` also fails on an em or en dash in the copy, anything loaded from another origin,
and broken local links or anchors. The `Site` workflow runs it on every pull request that
touches the site, and deploys from `main` once the repository is public and
Settings > Pages > Source is set to "GitHub Actions".

House rules for the copy: no em or en dashes, no tracking, and no user counts, stars, or
testimonials that don't exist. A comparison page is planned; the nav and footer have a
commented spot for its link.
